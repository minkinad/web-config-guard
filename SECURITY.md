# Безопасность

Пожалуйста, не публикуйте уязвимости в открытых issue. Используйте GitHub private vulnerability reporting, если он включён для репозитория; иначе свяжитесь с владельцем через приватный канал, указанный в профиле репозитория. Не прикладывайте рабочие секреты или чувствительные URL.

Поддерживаемая ветка: `main` до первого стабильного релиза. Security workflow запускает `govulncheck` и Gitleaks; CodeQL анализирует Go-код. Результаты этих автоматических проверок не заменяют review сетевых и файловых границ. Патчи безопасности должны сопровождаться регрессионным тестом.
