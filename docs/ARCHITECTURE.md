# Архитектура и аудит web-config-guard

## Что обнаружено

Проект уже реализовывал CLI для файлов/директорий/stdin и HTTP API. Парсер нормализует YAML/JSON; `guard` содержит интерфейс Rule, модели находок и обход дерева; `runner` собирает результаты и права файлов; `server` отдаёт REST; `cli` выбирает режим и exit code. Тесты покрывали правила, парсинг, runner и HTTP. Git-история содержит рефакторинг правил; несохранённые изменения README существовали до работы.

Сильные стороны: понятные маленькие пакеты, детерминированная сортировка находок, явный код завершения, ограничение HTTP payload. Слабые места: не было централизованных operational settings и graceful shutdown, CLI читал stdin/файлы без лимита, не было порога для CI, health существовал только как `/healthz`. Нет SARIF, baseline/diff, встраиваемых policy-наборов. Путь модуля `github.com/minkin/web-config-guard` отличается от текущего Git remote `github.com/minkinad/web-config-guard`; он оставлен ради совместимости импортов до отдельной миграции. Это технический долг, а не сломанный текущий сценарий.

## Решение

Структура сохранена. `internal/config/settings.go` добавлен отдельно от парсинга проверяемого документа. Приоритет: defaults → YAML → env → CLI flags. `--fail-on` — небольшая новая функция: находки всегда печатаются, код 1 возникает лишь при указанной минимальной severity. Значение по умолчанию `low` сохраняет прежнее поведение. HTTP `POST /v1/check`, `/healthz`, JSON schema, `--silent`, positional path и exit codes сохранены. Добавлены graceful shutdown, `slog`, request ID и новые health aliases.

## Риски

Правила эвристические: анализ одного дерева не учитывает реальный environment, inheritance и шаблоны. Parser не ограничивает вложенность YAML. HTTP API не аутентифицирован; по умолчанию слушает `:8080`, поэтому внешний доступ должен закрываться при эксплуатации. Ограничение CLI файла проверяется до чтения по `Stat`, что не защищает от гонки замены файла; следующий этап — bounded streaming reader. Полные имена файлов могут попадать в текстовый отчёт.
