# ADR 0001: Сохранить существующие пакеты и контракт CLI

Статус: принято.

Контекст: работающий проект с тестами; полная перестройка несла бы риск обратной несовместимости.

Решение: `guard.Rule` и `runner` остаются ядром. Operational settings добавлены в `config`, новая функция влияет только на CLI exit code. Endpoint `/healthz` сохранён как alias; новые health endpoints добавлены рядом.

Последствия: совместимость основных команд сохранена, но будущие policy-наборы потребуют отдельного формата конфигурации и миграционной политики.
